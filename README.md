# Saffron & Soul — Premium Pure-Vegetarian Restaurant (Page 1)

This is **Page 1 (Homepage)** of the multi-page project for **Saffron & Soul**, an editorial-grade, luxury pure-vegetarian Indian multi-cuisine restaurant.

## 🚀 How to Run Locally

1. **Extract this zip file** to your computer.
2. Open your terminal in the extracted folder:
   ```bash
   cd saffron-and-soul
   ```
3. **Install dependencies**:
   ```bash
   npm install
   ```
4. **Start the development server**:
   ```bash
   npm run dev
   ```
5. Open your browser at the URL shown in terminal (usually `http://localhost:5173`).
